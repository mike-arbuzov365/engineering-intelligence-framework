## Умови зупинки

Зупинитися і запитати власника лише якщо:

- знайдено реальний витік секрету чи приватних даних без безпечного виправлення в межах сесії;
- потрібна owner-only дія (push, release, видимість, PyPI, зміна живої конфігурації клієнта, hosted CI);
- залежність `mcp` має ліцензію поза політикою або не встановлюється поруч із базою EIF (S1, S4);
- G1 не пройдено після трьох ітерацій (гілка C);
- проти ratified рішення реєстру немає безпечного шляху без окремої пропозиції заміни;
- знайдено шлях, яким модель могла б викликати commit без схвалення людини (P0);
- target-файли мають несумісні паралельні зміни без безпечного узгодження;
- щось поза переліком призвело б до втрати даних або іншого незворотного ефекту.

Все решта (назви, структура файлів, дрібна неоднозначність схеми, недоступний клієнт, відсутній дозвіл на витрату) вирішується за [D-001..D-020 і Least-risk defaults](03-DECISIONS-022-eif-mcp.md) без зупинки.
