стан до виправлення й регресійну перевірку. Окремий запуск проти коду066e219

діагностиці: до виправлення перевірки інваріантів не проходили, після —3/3.

Наявний допоміжний експортер першого пакетного smoke викликав git stash create
до виявлення цієї поведінки. Це порушення протоколу виконання; його не
приховано. Посилання refs/stash не створювалося й не змінювалося. Експортер
замінено на git archive + binary diff/apply, повторні пакувальні перевірки
пройшли. Початкове підтвердження встановленого пакета також відкликано через
успадкований PYTHONPATH; його замінили перевірки фактичного місця імпортів.

Doctor у MCP навмисно показує неповне покриття: не читає предків і не запускає
зовнішні перевірки інтеграцій. Діагностика не повторює значень з недійсних
файлів. Номінальна схема статусів прогресу не оголошується структурним
валідатором пакетів. Прямий CLI зберіг26зразків виводу без змін.

## Knowledge Delta

### New facts

- MCP SDK2.1.1 підтримує потрібні публічні методи MCPServer і SDK-клієнт;
  перевірено пам’ять та stdio. Реальний стан клієнта з цього не випливає.
- Подвоєний вміст CallToolResult впливає на байтові межі. Ураховано обидві
  копії та екранування; кількість символів не дорівнює обсягу відповіді.
- Випробування встановленого пакета потребує перевірки фактичного місця
  імпортів. Сам факт побудови чи успішний запуск не виключають затінення
  вихідним деревом через PYTHONPATH.
