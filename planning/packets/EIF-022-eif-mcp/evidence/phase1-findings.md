# Реєстр зауважень фази 1

Усі перевірки використовують синтетичні локальні інстанси. Пріоритет означає
черговість виправлення, а не зовнішню сертифікацію безпеки. JEV викликано до
класифікації й огляду; загальний огляд вимагав ручного розбору. Підсумок
спирається на тести та незалежну перевірку меж. Програмні SDK-тести не є
ходами моделі в клієнті.

| Зауваження | Пріоритет і стан | Вхід та інваріант | До виправлення | Виправлення і перевірка |

| Linux і Python 3.12 | P3, відкрита межа покриття, JEV auto | Не заявляти непроведені перевірки | Python 3.12 недоступний, Linux не запускався | Збережено докази чистого Windows/Python 3.11 та встановленого пакета на 3.13; решта NOT RUN |

Огляд JEV повернув невпевнені оцінки рубрик без конкретного текстового переліку
дефектів. Докази SDK/пакування та чесне відкладення записів прийнято автоматично;
решту тверджень про схеми й межі перевірено прямими перевірками JSON Schema,
негативними SDK-тестами та читанням коду. Результат цього інструмента не
називається автоматичним схваленням.
