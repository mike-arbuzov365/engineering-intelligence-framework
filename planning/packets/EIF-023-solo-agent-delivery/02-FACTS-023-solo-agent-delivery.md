- Маршрути, свобода виконавця, вибір моделі, умовний пропуск етапів, розбіжності навичок → 001.
- Зовнішнє джерело знань, відновлення читання, фіксація сталих уроків, зв’язок із Knowledge Delta → 002 і 006.
- Незалежні тести, повторне приймання, блокування старих статусів і прив’язка до версії → 003 і 004.
- Точне завдання для виконавця та огляд доказів для оркестратора через обмежений інтерфейс читання → 004.
- Покажчик дизайн-системи, повторне використання компонентів, умовні UX-стани, повнота перевірок → 005.
- Відтворюване встановлення, робочі дерева Git, Windows stdio, цінність для соло-розробника і порівняння CLI/MCP → 006.
- Публікація, повномасштабне розгортання, запис через MCP, погодження людиною, масова міграція старих пакетів та зміна приватних проєктів → окремі доручення. Підстава для EIF-022b лишається чинною.
