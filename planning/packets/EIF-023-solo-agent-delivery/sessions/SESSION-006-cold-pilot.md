# Встановлення, новий чат і незалежне приймання

**Мета.** Визначити, що з пакета відтворюється в чистій інсталяції, у новому чаті та в робочому процесі власника. Критерії статуту — A1–A7.

Пілот має показати, чи лишилася проста задача простою і чи зупиниться складна задача після неприйнятої спроби. Попередній вимір розміру відповіді MCP та програмні перевірки дають базу для порівняння. Добери спосіб виміру під доступний клієнт і окремо зафіксуй, що зміг відтворити новий чат.

## Перед першою зміною

Прочитай [рішення](../03-DECISIONS-023-solo-agent-delivery.md) та записи за попередньою спробою. Звір актуальну базу й зачеплені матеріали: `scripts/tests/`, `docs/benchmarks/`, пакет установлення, ізольовані фікстури, заповнення 07-CLOSEOUT. У налаштованому сховищі знайди попередні рішення за темою цієї сесії; запиши в завданні або контрольній точці джерело, результат і вплив. Якщо інстанс не управляє пам’яттю, використовуй правило його власника. У репозиторії фреймворку почни з реєстру рішень.

## Обсяг

Зібрати локальний wheel з позначеним походженням, встановити в ізольоване середовище й виконати stdio self-test; перевірити завершення дочірнього процесу на Windows та описаний запасний шлях для пов’язаного робочого дерева Git. На однаковій початковій ревізії перевірити легку дію, RЕD/GREEN для регресії, пакет із поверненням, зовнішній і керований пошук та перенесення уроку наступному чату. Поведінковий тест пам’яті повинен приховувати урок від тексту запиту. За наявності погодженого хоста/бюджету дати новому чату тільки відомі джерела й вимоги, порівняти файли/CLI з MCP; окремо оцінювати зміну методики. Зарахувати лише дійсно виконані сценарії.

Власник не доручав публікацію, зміну клієнтських налаштувань або зовнішні витрати. Відсутню живу перевірку позначити невиконаною, не виводити економію зі статичного розміру відповіді.

## Перевірка

Запускати з кореня чистої копії з відповідними встановленими залежностями та вихідним кодом цієї ревізії. На додачу відтворити критерій нижче на відповідній фікстурі. Для нової поведінки записати точну команду нового прикладу в поверненні.

```text
python scripts/tests/test_eif_mcp_stdio.py
python scripts/tests/test_eif_mcp_package.py
python scripts/tests/test_skill_eval.py
python scripts/eif_check_links.py
python scripts/eif_privacy_scan.py
```
