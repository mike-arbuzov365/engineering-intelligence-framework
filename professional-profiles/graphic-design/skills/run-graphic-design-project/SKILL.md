# Run a graphic design project

1. Read `.eif/workspace-runtime/playbooks/graphic-design-project.md`.
2. Create or verify the brief with
   `.eif/workspace-runtime/templates/design-brief.md`.
3. Do not begin final production until inputs, constraints, acceptance criteria
   and the direction decision owner are known.
4. Close with `.eif/workspace-runtime/templates/design-delivery.md`.
5. Use the normal EIF Knowledge Delta for reusable learning. Do not promote a
   stakeholder's one-off preference into a general rule.
