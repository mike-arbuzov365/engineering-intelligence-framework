# Review graphic design delivery

1. Read sections 4–5 of
   `.eif/workspace-runtime/playbooks/graphic-design-project.md`.
2. Compare the actual deliverables with the approved brief. If no brief exists,
   name what cannot be verified instead of inventing criteria.
3. Inspect final exports at the target size or medium, not only editable files.
4. Separate defects from taste suggestions. Tie each finding to a criterion or
   likely consequence.
5. Record checks and open issues in
   `.eif/workspace-runtime/templates/design-delivery.md`.
