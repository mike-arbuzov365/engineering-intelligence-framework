# Onboard a software project

1. Read `.eif/workspace-runtime/playbooks/software-project-onboarding.md`.
2. Capture verified findings in
   `.eif/workspace-runtime/templates/software-project-baseline.md`.
3. Add only compact, stable project instructions below the EIF-managed marker
   in the active agent instruction file.
4. Keep normal planning and implementation in the existing EIF core workflows;
   do not create a second software-development process.
