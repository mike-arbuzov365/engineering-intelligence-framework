# Create a professional profile

Read and follow `.eif/runtime/playbooks/professional-profile-creation.md`.

Before writing, inspect `.eif/workspace.yaml`, existing workspace profiles and
the active public EIF skills. Create the smallest workspace-owned artifact set
that closes a repeated professional gap. Validate every profile with
`eifctl workspace doctor`; do not connect or update projects the owner has not
identified explicitly.
